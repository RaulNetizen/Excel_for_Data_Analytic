# Grocery Sales - Excel Analysis
## 📝 Descripción
Este repositorio contiene un proyecto de análisis de datos y Business Intelligence desarrollado en Microsoft Excel. El objetivo principal es analizar el comportamiento de compra de los clientes de una tienda de abarrotes mediante la integración de datos demográficos, productos, ventas y personal comercial, con el fin de generar insights que apoyen la toma de decisiones.
El proyecto aborda todo el flujo de análisis de datos, desde la limpieza y transformación de la información hasta la generación de indicadores clave y visualizaciones ejecutivas.
## 🎯 Objetivo
Analizar el desempeño comercial y los patrones de consumo de los clientes, integrando múltiples fuentes de datos para evaluar ventas, productos y vendedores, y comunicar los resultados de forma clara y estructurada.
## 🚀 Alcance y funcionalidades
- Integración de datos de clientes, productos, ventas y vendedores.
- Limpieza, validación y normalización de datos.
- Análisis del comportamiento de compra y patrones de consumo.
- Evaluación del desempeño de ventas por producto, ciudad y vendedor.
- Construcción de KPIs y dashboards interactivos en Excel.
🛠️ Tecnologías y herramientas
Microsoft Excel
- Tablas dinámicas
- Funciones lógicas y estadísticas
Análisis de datos
- Limpieza y transformación
- Visualización de indicadores clave
## 📈 Resultados principales
- Identificación de categorías de productos con mayor desempeño.
- Análisis del perfil y comportamiento de los clientes.
- Evaluación del rendimiento del equipo de ventas.
- Generación de dashboards para soporte a la toma de decisiones.
